Git commands:

Clone:
git clone URL

Check status:
git status

Stage everything:
git add .

Stage one file:
git add FILE

Commit:
git commit -m "MESSAGE"

Unstaging:
git restore --staged FILE

Push:
git push

Pull latest changes:
git pull

Create annotated tag:
git tag -a vx.x.x.x -m "MESSAGE"

Create annotated tag(for specific commit):
git tag -a vx.x.x.x [hash] -m "MESSAGE"

List tags:
git tag

Push tag:
git push origin vx.x.x.x

Push all tags:
git push --tags

Delete local tag:
git tag -d v1.0.0

Delete remote tag:
git push origin --delete [NAME OF TAG]

List all commits(from newest to oldest):
git log

Show Commit and Tag info:
git show [TAG NAME]

Version formats:
For developmental: vx.x.x.x-dev/patch.x
For stable: vx.x.x.x
Commit message: CTDS Development-x yyyy/mm/dd [time in 24h format]
(Note: Development number is separated by day. If changes are made within the same day, separate by letter.)
Commit message 2(for small commits): CTDS Development-x-[a-z] yyyy/mm/dd [time in 24h format]
