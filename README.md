# Centralized Task Distribution System (CTDS)

An experimental task distribution and hierarchical management system designed to streamline FRC team planning and coordination. CTDS aims to improve task delegation, organizational visibility, and workflow management through a centralized platform. Planned features include advanced quality-of-life improvements, team performance analysis, critical-area highlighting, extensive customization, and more.

**More to come soon.**

Current features:
 - AppBar
 - Main page
 - Two cards
 - Static element display
